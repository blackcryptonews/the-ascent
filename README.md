# The Ascent - Personal Transformation App

**Where every day is a step up.** Break through limiting beliefs and build unstoppable momentum with your personal AI coach, inspired by proven methodologies. Your journey to a transformed life starts here.

Built with Next.js 14, TypeScript, and OpenAI GPT-3.5 Turbo.

## Features

### ✨ Core Functionality
- **Daily Power Questions**: AI-generated personalized questions to drive reflection and growth
- **Habit Transformation**: Track habits you want to break or build
- **Pain & Pleasure Re-programmer**: The Dickens Pattern NLP technique with AI-guided visualization
- **Streak Tracking & Gamification**: Points system and daily streaks to maintain consistency
- **AI Coaching Insights**: Real-time feedback on your reflections

### 🧠 The Dickens Pattern (Pain & Pleasure Technique)
A powerful neuro-linguistic programming exercise that creates lasting change by:
1. **Linking intense PAIN** to your old behavior (visualizing 5 years of continuing the habit)
2. **Linking intense PLEASURE** to your new behavior (visualizing 5 years after transformation)

Your brain automatically moves away from pain and toward pleasure - this exercise rewires those associations.

## Tech Stack

- **Framework**: Next.js 14 with App Router
- **Language**: TypeScript
- **Database**: SQLite (dev) / PostgreSQL (production) with Prisma ORM
- **Authentication**: NextAuth.js with credentials provider
- **AI**: OpenAI GPT-3.5 Turbo (Free tier available)
- **Styling**: Tailwind CSS with custom glassmorphic design
- **Icons**: Lucide React
- **Deployment**: Vercel (optimized)

## Getting Started

### Prerequisites
- Node.js 18+
- npm or pnpm
- OpenAI API key (free tier: $5 credit for new accounts)

### Local Development

1. **Clone and install dependencies**
   ```bash
   cd the-ascent
   npm install
   ```

2. **Set up environment variables**

   The `.env` file is already configured for local development. Just add your OpenAI API key:
   ```
   OPENAI_API_KEY="sk-your-key-here"
   ```

   Get your free API key at: https://platform.openai.com/api-keys

3. **Initialize the database**
   ```bash
   npx prisma db push
   npx prisma generate
   ```

4. **Start the development server**
   ```bash
   npm run dev
   ```

5. **Open the app**
   Navigate to [http://localhost:3001](http://localhost:3001)

6. **Sign in or create account**
   - Go to Sign In page
   - Enter any email/password - accounts are auto-created for demo purposes

### Production Deployment

Ready to deploy? See [DEPLOYMENT.md](DEPLOYMENT.md) for complete instructions on deploying to Vercel with production database setup.

## Usage

### Daily Routine
1. Answer your daily power question (generated by AI based on your goals)
2. Get instant AI coaching insights on your reflection
3. Track your streak and earn points

### Transform a Habit
1. Go to "My Habits" and create a new transformation goal
2. Click "Start Transform" to begin the Pain & Pleasure exercise
3. Experience AI-generated scenarios for your future
4. Rate the emotional intensity to solidify the neuro-associations
5. Revisit the exercise whenever you need reinforcement

## Database Schema

The app uses SQLite with the following main tables:
- `users` - User accounts
- `user_profiles` - Goals, focus areas, and personalization
- `daily_questions` - Power questions and responses
- `habits` - Transformation goals
- `pain_pleasure_exercises` - Completed transformation exercises
- `ai_insights` - AI-generated coaching insights
- `activity_logs` - Points and streak tracking
